# Lumen Web Studio

A single landing page for **solar installation companies** — websites that turn visitors into leads, live in a week.

**Goal:** make a prospect trust the studio and **book a free call.**

- One page, 8 sections (Header · Hero · Services · Proof · Process · About · Final CTA · Footer).
- React + Vite + Tailwind, static build, deployed on GitHub Pages.
- No backend, no database, no CMS — every "Book a free call" links to Calendly.

## Repo map
Start at **`claude.md`** — it routes you to every folder and doc. The build brief is `agency-website-brief.md`; all decisions and copy live under `docs/`.
