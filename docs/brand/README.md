# docs/brand/ — Who we are, how we sound

This folder defines **Lumen Web Studio** as a brand and a voice — the tone every word uses. It is **voice only.** The visual system lives in `docs/design/` (see note below).

## Files

| File | Answers | Use it when |
|------|---------|-------------|
| `README.md` | Where the voice lives and where the look lives. | Starting any creative work. |
| `BRAND.md` | What do we say, and how do we sound? | Writing or judging any copy, headline, card text. |

## Ground rules (from the brief)
- Voice: plain English, outcome-first, confident but calm, honest. No agency buzzwords.
- Copy locked in `docs/content/PAGE-COPY.md`; CTA wording fixed as `Book a free call`.

> **Where the visual system went:** the old `DESIGN-SYSTEM.md` moved to **`docs/design/`** (`DESIGN-SYSTEM.md`, `DESIGN-TOKENS.md`, `UI-PATTERNS.md`, `QUALITY-BAR.md`) to keep one source of truth for pixels. Brand = voice; design = looks.

Locked identity facts (name, color, Calendly link) live in `docs/decisions/ADR-0002-brand-facts.md`.
