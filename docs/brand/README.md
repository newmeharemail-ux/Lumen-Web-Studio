# docs/brand/ — Who we are, how we sound, how we look

This folder defines **Lumen Web Studio** as a brand — the voice every word uses and the visual system every pixel follows. It exists so the site looks and reads like one person made it: confident, honest, clean.

## Files

| File | Answers | Use it when |
|------|---------|-------------|
| `BRAND.md` | What do we say, and how do we sound? | Writing or judging any copy, headline, card text. |
| `DESIGN-SYSTEM.md` | What do we look like? Colors, font, spacing, buttons. | Styling anything, or adding a new visual element. |

## Ground rules (from the brief)
- One accent color **#ADEBB3**, used for **buttons and highlights only**.
- One font: **Inter**, everywhere.
- Everything else: black, white, neutrals.
- Tone: high-end creative studio — calm, premium, but honest. No hype.

Locked identity facts (name, color, Calendly link) live in `docs/decisions/ADR-0002-brand-facts.md`.
