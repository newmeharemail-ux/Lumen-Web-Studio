# ADR-0002 — Brand facts: name, color, font, booking link, niche

- **Date:** 2026-08-08
- **Status:** Accepted — confirmed by the owner in-session

## Context
The name, accent color, and booking link are non-negotiable brand inputs (brief §2).

## Decision
| Fact | Value |
|------|-------|
| **Agency name** | **Lumen Web Studio** (as the brief's field requires; earlier "Lumenn" was a typo). |
| **Niche** | Solar installation companies. |
| **Outcome promise** | *"Websites that turn visitors into leads for your business."* |
| **Accent color** | **#ADEBB3** — buttons/highlights only. |
| **Font** | **Inter** — one font everywhere. |
| **Booking link** | `https://calendly.com/newmeharemail/30min` — Calendly only, never a form. |
| **Proof assets** | `Demo-Build-Ecogreen/` (3 real screenshots). |

## Consequences
- Any doc/site showing a different name, color, or font is wrong; route back here.
- Placeholder `contact@lumenwebstudio.com` + phone are interim and must be replaced before launch (flagged in `PAGE-COPY.md`).
